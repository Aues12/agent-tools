# Experiments

Applications here preserve earlier explorations. They are independently
runnable where their local README says so, but are not v0.1 examples or
compatible with the v0.1 `semantic_graph` JSON contract by default.

[`writing_timeline/`](writing_timeline/) uses an older directed graph schema
with string node IDs and dated posts. Its bundled graph is synthetic. The
original large graph came from a separate source and is retained only in Git
history and the private `agent-tools-dev` copy.
