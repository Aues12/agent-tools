# Project Memory Chronology — 2026-08

## 2026-08-02

Type: `commit-backed`

* `file-tools/semantic_cpg/`

Interpretation:

This is the point where Semantic Observatory's relation-localization model
becomes structurally broader than calls and value movement. `semantic_cfg`
captures local execution paths, while `semantic_cpg` provides a unified graph
surface for future projection layers. The CPG is not a UI by itself; it is the
analysis substrate from which multiple deterministic views can be projected.

Affected layers:

* control-flow localization
* relation localization
* unified analysis localization
* projection-layer readiness

Interpretation:

until they receive stable construction grammar and JSON contracts.
