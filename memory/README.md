# Memory

Memory stores long-lived information. It is separate from current runtime state.

Initial categories:

* `procedural/`: reusable knowledge about how tasks are commonly performed.
* `semantic_observatory/`: stable conceptual language, theory, and semantic
  structures used to interpret the repository.
* `task_history/`: previous task summaries and outcomes.
* `project_memory/`: repository-specific conventions, architectural decisions,
  and development chronology.
* `preferences/`: durable user or system preferences.
