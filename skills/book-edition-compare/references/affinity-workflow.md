# Affinity editing and PDF export

This workflow was observed in Affinity on macOS with a Turkish interface; menu labels, shortcuts and window layout may vary by platform, language and version. Reinspect the current UI after actions and use current control labels rather than saved element IDs or screen coordinates.

1. Open or select the intended `.af` file and confirm the document and edition before editing. Open **Bul ve Değiştir** with Command+F on macOS (Ctrl+F on Windows), or use the relevant menu if the shortcut differs. Set **Kapsam** to **Belge** when searching the document.
2. Enter the exact erroneous text in **Bul**, run the search and inspect the result count and surrounding text. Select the result matching the requested location and context. If more than one occurrence exists, use **Değiştir** on the selected match; do not use **Tümünü Değiştir** unless every occurrence is explicitly within scope. Use the smallest suitable replacement to preserve surrounding formatting. Repeat for the authorized corrections; if a match is ambiguous, do not guess.
3. Re-run searches or inspect the edited passages to confirm replacements. Search result lists can remain stale immediately after replacement; refresh the search before drawing conclusions. Save the source and verify the save completed.
4. When a PDF is required, use **Dosya → Dışa Aktar → Dışa Aktar…**. Preserve the source edition's relevant export preset and settings, such as PDF/X variant and page range, when known; do not assume an observed preset applies to every book. If a preflight warning appears, preflight review is not required for this workflow: continue past it without changing unrelated content. Do not claim that preflight passed or that unexamined issues were resolved.
5. Export under a distinct name, and inspect the save dialog and final file path to ensure the original PDF was not overwritten. Verify that the output exists, contains each corrected passage, and retains the expected page count. Inspect affected pages for changed line or page flow where appropriate. If text extraction is ambiguous, verify the rendered page. When reporting locations, separately verify the PDF viewer page number and the page number printed in the book.
