# manuscript_find_replace

Read SKILL.yaml before use. Search first, inspect contexts and warnings, then pass the exact source digest, total count, and explicit match IDs to replace. Never overwrite an existing file. DOCX support is limited to ordinary body and table text runs; inspect unsupported-structure warnings. Replacements spanning runs inherit the first run's formatting. Render and inspect edited DOCX before publication. Keep Python API and JSON operations aligned and test normal, invalid and boundary cases.
